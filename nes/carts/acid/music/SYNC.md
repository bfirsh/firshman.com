# Acid: music sync sheet

Song 0, **"Acid"**: acid techno in A minor, generated by `tools/gen_song.py` into `song.txt`
(format: `tools/compile.py`). The driver is frame-locked; the tempo never changes.

| | |
| --- | --- |
| Frames per row | **7** (a 16th note) |
| Rows per pattern | **64** (4 bars) |
| Frames per beat / bar / pattern | 28 / 112 / **448** |
| BPM | 128.8 (NTSC, 60.0988 frames/s) |
| Length | 22 patterns = **9,856 frames** = 2:44.0, loops to order 0 seamlessly |

## Channels

- **Pulse 1, the 303.** Duty + volume envelopes act as the filter: 12.5% (open, nasal) sweeping
  to 25% and 50% (closed) within each 16th. Six cutoff levels x normal/accent instruments
  (`a0`-`a5`, `x0`-`x5`), the accent ones louder with a d0/d1 "wow" (resonance). `~` notes are
  303 slides: the driver's new `$E6` command makes the next note glide in (portamento) without
  retriggering the envelope. Riffs mutate bar by bar; the cutoff opens over the builds.
- **Pulse 2.** Stabbed minor chords (`{arp 37}`: Am, Dm, Em, Gm, Cm, Fm), a dub echo of the
  303 in the breakdown (the driver's echo mode), a rising siren in the last bar of each build.
- **Triangle.** The four-to-the-floor kick: a 9-frame pitch dive from A4 to A1 on every beat.
  Breathing sub notes in the breakdown.
- **Noise.** Quiet 8th ticks, 16th closed hats, open off-beat hats (some in metallic short mode),
  crashes, the two-pattern rising sweep (period 15 -> 0, rate 28), a snare roll in the breaks.
- **DMC.** Synthesised by `tools/dpcm.py`: kick punch (layered with the triangle on 1 and 3),
  clap (three bursts + tail), drop boom, zap (resonant blip), rim.

## Events (`music_events`)

bit2 kick (triangle kick, DMC kick/boom), bit3 snare (DMC clap, noise snare), bit4 hat,
**bit5 = 303 accent**, **bit6 = every 303 note**. Extra exports for the visuals: `music_p1v`
(the 303's output volume this frame), `music_p1d` (its duty: 0 = filter open), `music_p2v`.

## Verification

`python3 tools/verify.py --out DIR` (renders the test ROM twice through the song):
timing, events (kick 326, snare 222, hat 806, accent 358, 303 note 1238 per pass, frame-exact),
APU periods against the score (slides checked once they arrive), f0 of long notes from the solo
audio, the drop's envelopes frame-exact, no stuck notes, APU state identical on the second pass,
no click at the loop seam, peak -8 dBFS with no clipping, worst-case `music_play` ~1,820 cycles.
The band-level correlation of pass 2 vs pass 1 reads 0.92-0.95 rather than 0.97: the APU
registers are identical frame by frame; the pulses' phase is not reset on the second pass.
